# Expense Tracker & Reminder App

A modern, responsive, and easy-to-use web application built with HTML, CSS, and JavaScript to track daily expenses, categorize spending, and manage a personal budget.

## Features
* 💰 **Total Expense Calculation:** Automatically computes and updates total spending in real-time.
* 🏷️ **Category Sorting:** Classify expenses into Food, Travel, Bills, Shopping, and more.
* 📅 **Date Tracking:** Automatically tags each transaction with the exact date.
* 💾 **Local Storage:** Safely stores your transaction history in the browser so data persists across refreshes.
* 🎨 **Modern Glassmorphism UI:** Clean, elegant card design styled with Poppins font and FontAwesome icons.

## Tech Stack
* **HTML5**
* **CSS3 (Flexbox & Custom Properties)**
* **JavaScript (ES6, LocalStorage API)**

## How to Run
1. Clone the repository or download the source files (`index.html` & `script.js`).
2. Open `index.html` in any modern web browser or use VS Code Live Server.
3. Start adding and managing your daily expenses!
